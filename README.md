Projeto desenvolvido em Java para simular a gestão e o acervo de uma livraria/biblioteca, aplicando conceitos avançados de Programação Orientada a Objetos (POO).
O sistema permite o registo de utilizadores e diferentes tipos de itens do acervo (como Livros e HQs). O programa gere a disponibilidade dos itens, calcula prazos de devolução específicos para cada categoria e realiza a lógica de empréstimos.

objetivo do projeto:
Feito para praticar meus aprendizados de Java POO.

O que foi usado na criacao:
-Java (JDK)
-Orientação a Objetos (POO): Herança, Polimorfismo, Classes Abstratas e Encapsulamento.
-Coleções (List, ArrayList): Gestão em memória dos utilizadores e do acervo.
-Polimorfismo: Regras de negócio personalizadas para o cálculo do prazo de devolução dependendo do tipo de item.

Proximos passos:
- Integração com o SQL. Substituir a persistência de dados em memória (ArrayList) por uma base de dados relacional.
-Refatoração da camada de dados: Criação de queries para consulta, registo e atualização de empréstimos via base de dados.

Como utilizar o projeto:
-Certifica-te de que tens o Java JDK instalado no teu computador.
- Abre a pasta do projeto na tua IDE favorita (IntelliJ IDEA, Eclipse, VS Code, etc.).
- Executa a classe principal Main.java.
